Overview#

annoray’s containers are xarray’s: a DataArray is an N-dimensional array with named dimensions, coordinates and attributes, and a Dataset is a dict-like collection of them sharing dimensions. What annoray adds is that the data carries a physical unit, checked by every operation. The code on this page runs when the documentation is built.

Arrays with units#

import numpy as np
import annoray as ar

temp = ar.DataArray(
    np.array([[281.2, 283.9, 279.5], [285.0, 287.3, 284.1]]),
    dims=("time", "station"),
    coords={"time": ar.date_range("2026-07-01", 2, "D"), "station": ["a", "b", "c"]},
    name="temperature",
    units="K",
)
temp

<annoray.DataArray "temperature" (time: 2, station: 3)> Size: 48B
[[281.2, 283.9, 279.5],
 [285, 287.3, 284.1]]
Units: K
Coordinates:
  * time    (time) datetime 2026-07-01 00:00:00 2026-07-02 00:00:00
  * station (station) str "a" "b" "c"

Units propagate through arithmetic and convert exactly:

print(temp.to("degC").values)
print((temp.mean("time") - temp.min("time")).units)  # a kelvin-sized step

[[ 8.05 10.75  6.35]
 [11.85 14.15 10.95]]
K

Dimensionally inconsistent operations raise instead of producing a number:

try:
    temp + ar.Quantity(3.0, "m")
except ar.UnitError as e:
    print("UnitError:", e)

UnitError: incompatible units: K and m

A bare number beside data with a unit is accepted only as 0 or NaN; other values are given as quantities, so a threshold cannot silently be in the wrong unit:

warm = temp.where(temp > ar.Quantity(10.0, "degC"))
print(warm.values)

[[  nan 283.9   nan]
 [285.  287.3 284.1]]

Selecting#

Positional and label-based selection follow xarray; label slices include both ends.

print(temp.isel(time=0).values)
print(temp.sel(station=["a", "c"], time="2026-07-02").values)

[281.2 283.9 279.5]
[[285.  284.1]]

Updating values#

Values are immutable from Python: an array’s data never changes underneath a reference to it. Containers are not: a Dataset is a mutable collection of immutable variables, and a DataArray’s coordinates, attributes and name can be changed, but its data and unit are fixed for its lifetime.

Values

Replaceable in place

DataArray

immutable (da[...] = v and .values[...] = v raise)

coordinates, attrs, name

Dataset

immutable (each variable’s)

variables (ds["v"] = ..., del ds["v"], update), coordinates, attrs

put() (by position) and put_sel() (by label) return an updated copy, converting the value into the array’s unit:

fixed = temp.put_sel(ar.Quantity(9.0, "degC"), station="b", time="2026-07-01")
print(fixed.values)
print(temp.values[0, 1])  # unchanged

[[281.2  282.15 279.5 ]
 [285.   287.3  284.1 ]]
283.9

A dataset has no put of its own: a variable is edited with put and put back, which replaces it in the dataset (or assign gives a new dataset and leaves this one as it was). Arrays taken from the dataset before keep their values:

ds = temp.to_dataset()
before = ds["temperature"]
ds["temperature"] = ds["temperature"].put_sel(ar.Quantity(9.0, "degC"), station="b")
print(ds["temperature"].values[:, 1])
print(before.values[:, 1])  # unchanged

[282.15 282.15]
[283.9 287.3]

Adding values#

An array grows along a dimension with concat(); there is no append method. A new value is a one-element array with its coordinate, in any compatible unit (it is converted into the first array’s):

point = ar.DataArray(
    [[9.0, 11.0, 7.5]],
    dims=("time", "station"),
    coords={"time": [np.datetime64("2026-07-03", "ns")], "station": ["a", "b", "c"]},
    units="degC",
)
longer = ar.concat([temp, point], dim="time")
print(longer.sizes, longer.values[-1])

{'time': 3, 'station': 3} [282.15 284.15 280.65]

Since values are immutable, each concat copies everything it joins, so growing an array one value at a time in a loop takes time quadratic in its length. Values that arrive one by one are collected first and joined in a single concat:

pieces = [temp]
for day in range(3, 6):
    t = np.datetime64("2026-07-01", "ns") + np.timedelta64(day - 1, "D")
    pieces.append(point.assign_coords(time=[t]))
print(ar.concat(pieces, dim="time").sizes)

{'time': 5, 'station': 3}

Values streamed to a file go through NetcdfWriter, whose append grows the file in place without rewriting what is already written.

Grouping and windows#

hourly = ar.DataArray(
    288.0 + 0.1 * np.arange(72) + 5.0 * np.sin(np.arange(72) * 2 * np.pi / 24),
    dims="time",
    coords={"time": ar.date_range("2026-07-01", 72, "h")},
    units="K",
)
print(hourly.resample(time="1D").mean().values)
print(hourly.rolling(time=24).mean().dropna("time").values[:3])

[289.15 291.55 293.95]
[289.15 289.25 289.35]

Times and time zones#

Date-times are datetime64[ns] instants in UTC. A variable of them can carry a time zone, which sets the wall-clock times its components, resampling bins and display use; times that know their zone (whenever’s, timezone-aware datetimes, pandas’) keep it when they become an array. The time chapter covers the details.

local = hourly.assign_coords(time=hourly.time.dt.tz_convert("America/New_York"))
print(local.time.dt.hour.values[:3])  # 20:00, 21:00, 22:00 on the evening before
print(local.resample(time="1D").mean().sizes)  # local days: one more than in UTC

[20 21 22]
{'time': 4}

Files#

netCDF and Zarr are read and written by annoray’s own backends. Files open lazily: selections and reductions read only what they need, in slabs within a memory budget.

import tempfile, os

path = os.path.join(tempfile.mkdtemp(), "temperature.nc")
temp.to_dataset().to_netcdf(path)

ds = ar.open_dataset(path)  # lazy, memory-mapped
print(ds["temperature"].is_lazy, ds["temperature"].units)
print(ds["temperature"].mean("time").to("degC").values)

True K
[ 9.95 12.45  8.65]

In Rust#

The same model, with the dimensional check available at compile time as well:

use annoray::io::open_dataset;
use annoray::sel;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let ds = open_dataset("temperature.nc")?; // lazy, memory-mapped
    let t = ds.get("temperature")?;
    let a = sel!(t[station = "a"])?;
    println!("{}", a.mean("time")?.to_unit(&"degC".parse()?)?);
    Ok(())
}
