DataArray#

A labelled, units-aware N-dimensional array.

DataArray(data[, dims, coords, name, attrs, ...])

A labelled, units-aware N-dimensional array (xarray's DataArray).

Each section has a short example; the examples share this setup:

import numpy as np
import annoray as ar

temp = ar.DataArray(
    280.0 + np.arange(12.0).reshape(4, 3),
    dims=("time", "station"),
    coords={"time": ar.date_range("2026-07-01", 4, "D"), "station": ["a", "b", "c"]},
    name="temperature",
    units="K",
)
temp

The number of elements.

DataArray.ndim

The number of dimensions.

DataArray.dtype

The numpy dtype of .values.

DataArray.values

The values as numpy: a read-only view (no copy) for numbers in memory.

DataArray.data

Same as .values.

DataArray.name

The array's name (None if unnamed); assignable.

DataArray.attrs

The attributes, as a dict whose changes are applied to this array (and, for an array taken from a dataset, to that dataset's variable).

DataArray.encoding

How the data is (or will be) stored on disk, in xarray's encoding names (dtype, _FillValue, scale_factor, units/calendar of times, zlib, complevel, chunksizes, compression, …); changes apply to this array (and to the dataset variable it came from).

DataArray.coords

Coordinates, as data arrays, in a dict whose assignments (da.coords["x"] = …) and deletions apply to this array.

DataArray.indexes

Dimension → pandas index, for dimensions with a coordinate.

DataArray.xindexes

Dimension → pandas index, as indexes.

DataArray.nbytes

Bytes of the data (not read for lazy data).

DataArray.chunks

None: annoray does not use dask.

DataArray.T

The transpose (dimensions reversed).

DataArray.is_lazy

Whether the values are still on disk (read on demand).

DataArray.loc

Label-based indexing by position: da.loc[10.0], da.loc[:, "a":"c"], da.loc[{"x": 10.0}] (read only).
