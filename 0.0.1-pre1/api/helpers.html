GroupBy, windows and weights#

Objects returned by DataArray.groupby() / DataArray.resample(), DataArray.rolling(), DataArray.rolling_exp(), DataArray.coarsen() and DataArray.weighted() (and their Dataset counterparts). Each reduction returns a new object with the grouped or windowed dimension reduced.

Each section has a short example; the examples share this setup:

import numpy as np
import annoray as ar

hourly = ar.DataArray(
    288.0 + 5.0 * np.sin(np.arange(48) * 2 * np.pi / 24),
    dims="time",
    coords={"time": ar.date_range("2026-07-01", 48, "h")},
    units="K",
)

GroupBy#

by_hour = hourly.groupby("time.hour")
print(by_hour.mean().sizes)
print(hourly.resample(time="1D").max().values)
print(hourly.resample(time="1D").quantile(0.5).values)

{'hour': 24}
[293. 293.]
[288. 288.]

GroupBy.first()

The first element of each group.

GroupBy.last()

The last element of each group.

GroupBy.quantile(q[, dim])

Quantiles of each group (over the grouped dimension by default).

GroupBy.map(func[, args, shortcut])

func(group, *args, **kwargs) for every group, combined: results that keep the grouped dimension go back to the original order; others are stacked along the group dimension (xarray's GroupBy.map).

GroupBy.reduce(func[, dim])

func(values, axis=…) over each group (the grouped dimension by default).

Weighted#

weights = ar.DataArray(np.where(np.arange(48) % 24 < 12, 2.0, 1.0), dims="time")
w = hourly.weighted(weights)
print(w.mean("time").item(), w.sum_of_weights().item())

289.0549658489897 K 72.0
