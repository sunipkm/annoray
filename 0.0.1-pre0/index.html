annoray#

Annotated arrays: the xarray data model (labelled N-dimensional arrays with named dimensions, coordinates and attributes) in Rust, with physical units built in and Python bindings that follow xarray’s API. netCDF-3, netCDF-4/HDF5 and Zarr are read and written by pure-Rust backends, with no C dependencies.
