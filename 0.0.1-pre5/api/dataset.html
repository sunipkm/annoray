Dataset#

A dict-like collection of data arrays sharing dimensions and coordinates.

Dataset([data_vars, coords, attrs])

A units-aware collection of labelled arrays sharing dimensions (xarray's Dataset).

Each section has a short example; the examples share this setup:

import numpy as np
import annoray as ar

ds = ar.Dataset(
    {
        "temperature": (("time", "station"), 280.0 + np.arange(12.0).reshape(4, 3), {"units": "K"}),
        "pressure": ("time", [1012.0, 1009.5, 1004.2, 1007.8], {"units": "hPa"}),
    },
    coords={"time": ar.date_range("2026-07-01", 4, "D"), "station": ["a", "b", "c"]},
)
ds

Dataset-level storage settings (unlimited_dims); changes apply to this dataset.

Coordinates, as data arrays, in a dict whose assignments (ds.coords["x"] = …) and deletions apply to this dataset.

The data variables, as a live dict: ds.data_vars["v"] = ... adds or replaces one.

Dataset.nbytes

Bytes of all variables (not read for lazy data).

Dataset.chunks

{}: annoray does not use dask.

Dataset.loc

Label-based indexing with a mapping: ds.loc[{"x": 10.0}] (read only).

Contents#

# Variables are replaced, never written into: arrays taken earlier keep their values.
edited = ds.copy()
before = edited["pressure"]
edited["pressure"] = edited["pressure"].to("Pa")
print(before.units, edited["pressure"].units)
wind = ar.DataArray([3.0, 5.5, 2.1, 4.0], dims="time", units="m/s")
print(list(ds.assign(wind=wind).data_vars))  # a new dataset; ds is unchanged

Dataset.groupby(group)

Group by the values of a coordinate or variable ("time.month" for a datetime component): reductions give one value per group, arithmetic with a per-group object broadcasts back (ds.groupby("time.month") - clim).

Dataset.groupby_bins(group, bins[, right, ...])

Group into bins of a coordinate's values: bins is a number of equal-width bins or their edges; right closes bins on the right, include_lowest closes the first on the left.

Dataset.resample([indexer])

Resample along a datetime dimension: ds.resample(time="1D").mean().

Dataset.rolling([dim, center, min_periods])

A moving window along one or more dimensions: ds.rolling(time=24).mean(); center labels windows at their centre, min_periods sets the number of valid values a window needs.

Dataset.rolling_exp([window, window_type, ...])

Exponentially weighted moving statistics of every variable along the dimension.

Dataset.coarsen([dim, boundary, side, ...])

Block reductions of every variable: ds.coarsen(time=4).mean().

Dataset.weighted(weights)

Weighted reductions of every numeric variable: ds.weighted(w).mean("lat").
