Top-level functions#

Each section has a short example; the examples share this setup:

import os
import tempfile

import numpy as np
import annoray as ar

tmp = tempfile.mkdtemp()
temp = ar.DataArray(
    280.0 + np.arange(6.0),
    dims="time",
    coords={"time": ar.date_range("2026-07-01", 6, "D")},
    name="temperature",
    units="K",
)

Opening and saving#

temp.to_netcdf(os.path.join(tmp, "t.nc"))
ds = ar.open_dataset(os.path.join(tmp, "t.nc"))  # lazy: values are read when used
print(ds["temperature"].is_lazy, ds["temperature"].units)
print(ar.load_dataset(os.path.join(tmp, "t.nc"))["temperature"].is_lazy)

open_dataset, open_datatree and open_mfdataset take limits= for files from untrusted sources ("untrusted", or a dict of limits; see files from untrusted sources); a file that breaches them raises ReadLimitError.

open_dataset(path, *[, group, ...])

Open a netCDF-3/4, HDF5 file or Zarr store lazily and CF-decode it (xarray's open_dataset).

open_dataarray(filename_or_obj, **kwargs)

Open a file holding one data variable, as a DataArray.

open_datatree(path, *[, mask_and_scale, ...])

Open every group of a netCDF-4/HDF5 file or Zarr store as a DataTree (lazily).

open_groups(filename_or_obj, **kwargs)

Every group of a file (or Zarr store) as a dataset, by path.

open_mfdataset(paths, *[, concat_dim, lazy, ...])

Open several files as one dataset (xarray's open_mfdataset): a glob pattern or a list of paths, combined by their coordinates (combine="by_coords") or concatenated along concat_dim in the order given (combine="nested").

open_zarr(store[, group])

Open a Zarr store (v2 or v3 directory) lazily and CF-decode it; open_dataset recognises stores too.

load_dataset(filename_or_obj, **kwargs)

open_dataset with every variable read into memory.

load_dataarray(filename_or_obj, **kwargs)

open_dataarray with the data read into memory.

decode_cf(obj, *[, mask_and_scale, ...])

CF-decode a dataset opened (or built) without decoding (xarray's decode_cf): times, packing, fill values, units and coordinates, by the same rules as open_dataset.

to_netcdf(obj, path, **kwargs)

Write an annoray Dataset or DataTree (or, with xarray installed, an xarray.Dataset) with annoray's pure-Rust writers.

to_zarr(obj, store, **kwargs)

Write an annoray Dataset (or DataArray, as a one-variable dataset) as a Zarr store; see Dataset.to_zarr.

save_mfdataset(datasets, paths[, mode])

Write each dataset to its path.

ReadLimitError

A file breaches the read limits it was opened with (limits= of open_dataset).

Writing in place#

template = temp.isel(time=slice(0, 0)).to_dataset()
with ar.NetcdfWriter.create(os.path.join(tmp, "run.nc"), template, unlimited_dims=["time"]) as w:
    for i in range(3):
        w.append(temp.isel(time=slice(i, i + 1)).to_dataset(), "time")
    print(w.dim_len("time"))
print(ar.open_dataset(os.path.join(tmp, "run.nc"))["temperature"].values)

NetcdfWriter(path)

A netCDF-4 file open for writing in place.

NetcdfWriter.create(path, template, *[, ...])

A new netCDF-4 file from template (see the class documentation); encoding and unlimited_dims as for to_netcdf.

NetcdfWriter.write(ds[, region])

Write ds into the file: along each dimension of region (dimension → start, or a slice), from there; along the others, from 0.

NetcdfWriter.append(ds, dim)

Append ds along the unlimited dimension dim: it must hold every variable of the file along dim.

NetcdfWriter.dim_len(dim)

NetcdfWriter.dataset()

The file as it now is, opened lazily (writes what is buffered first).

NetcdfWriter.flush()

Write what is buffered.

NetcdfWriter.close()

Write what is buffered and close (further calls fail).

NetcdfWriter.closed

Whether close() has run.

concat(objs, dim, *[, data_vars, coords, ...])

Concatenate data arrays (or datasets) along a dimension (new or existing).

merge(objs, *[, join, compat])

Merge datasets (or named data arrays) into one dataset; compat decides variables of the same name ("override", "equals", "identical", "no_conflicts").

align(*objs[, join])

Align objects on their shared dimension coordinates; dimensions in exclude are left as they are (not aligned).

broadcast(*args[, exclude])

Data arrays aligned (outer join) and broadcast against one another.

combine_by_coords(data_objects, **kwargs)

Combine datasets that tile one dimension, ordered by its coordinate (xarray's combine_by_coords); datasets that do not differ along any dimension are merged.

combine_nested(datasets, concat_dim, *[, join])

Combine a nested list of datasets (or arrays): the outer level along the first of concat_dim, the next along the second, …; None merges that level.

date_range(start, periods, freq)

Regular dates (xarray's date_range; annoray's date_range(start, periods, freq) positional form also works): numpy datetime64 for the standard calendars (through pandas, as xarray; periods without pandas), CF dates for other calendars or with use_cftime=True (fixed steps and period starts MS/QS/YS, from start with periods or up to end).

Streaming and options#

Lazy data (opened from files, or computed from it) is reduced and written in slabs within a memory budget.

print(ar.stream_bytes())
ar.set_stream_bytes(16 * 2**20)  # reductions of lazy data read 16 MiB at a time
ar.set_stream_bytes(64 * 2**20)

67108864

The units quantities hold are interned: kept once per spelling in a process-wide table that only grows, capped at 65,536 units by default. Past the cap, a quantity in a new unit is a UnitError; units already interned keep working.

print(ar.interned(), ar.intern_cap())
ar.set_intern_cap(10_000)  # a tighter bound, for a service reading untrusted files
ar.set_intern_cap(65_536)

1 65536

set_stream_bytes(bytes)

Set the streaming budget (default 64 MiB): how much on-disk data reductions of lazy data (mean, sum, std, var, min, max) read at a time, and how many bytes of chunks reading and writing decode or compress at once.

stream_bytes()

The current streaming budget, in bytes.

set_intern_cap(cap)

Set the cap on interned units (default 65,536): the units quantities hold are kept once per spelling in a process-wide table that only grows, and past the cap a quantity in a new unit is a UnitError.

intern_cap()

The cap on interned units.

interned()

The number of units interned so far.

set_options(**kwargs)

xarray's set_options, as a call or a with block.

get_options()

The options annoray always uses (see set_options).

show_versions([file])

The versions of annoray, Python, numpy and the optional dependencies.

Extending#

@ar.register_dataarray_accessor("climate")
class Climate:
    def __init__(self, da):
        self._da = da

    def anomaly(self):
        return self._da - self._da.mean()

print(temp.climate.anomaly().values)
