Units#

Units belong to the data: da.units is a Unit, scalars with units are Quantity values, and a CF units attribute is decoded into a unit when a file is opened. Dimensionally inconsistent operations raise UnitError.

Unit(unit)

A unit of measurement (Unit("m s-1"), Unit("degC")), parsed and checked when made.

Quantity(magnitude[, units])

A number with a unit (Quantity(2.5, "km"), Quantity(3+4j, "V"), or 2.5 * Unit("km")): annoray's Rust Quantity, with its dimension checked at run time; the number is a float or a complex.

Dimension(*[, mass, length, time, current, ...])

A physical dimension: the exponents of the base quantities (the seven SI ones and angle).

UnitError

Incompatible or unknown units (e.g. adding metres to seconds).

dimension(name, dim[, doc])

A named dimension made at run time.

Each section has a short example; the examples share this setup:

import annoray as ar

Unit#

u = ar.Unit("km/h")
print(u.dimension, u.si_factor, u.is_convertible("m/s"))
print(ar.Unit("degC").kind, ar.Unit("degC").offset)

m s-1 0.2777777777777778 True
affine 273.15

Unit.dimension

The unit's dimension.

Unit.dimensionless

Whether this unit has no dimension (1, %, rad is an angle and is not).

Unit.is_convertible(other)

Whether values convert between this unit and other (same dimension).

Unit.kind

"linear", "affine" (°C), "epoch" (days since …) or "log" (dB).

Unit.offset

The zero offset of an affine unit, in its own scale (273.15 for °C); else None.

Unit.si_factor

The factor to coherent SI base units (and radians): value_SI = (value + offset) · si_factor.

Unit.canonical

The unit in canonical form (prime-factorised scale, base dimensions).

Unit.to_astropy()

As an astropy.units.UnitBase (needs astropy).

Quantity#

q = ar.Quantity(90.0, "km/h")
print(q.to("m/s"), q.magnitude, q.units)
try:
    q + ar.Quantity(1.0, "kg")
except ar.UnitError as e:
    print("UnitError:", e)
# A complex magnitude: the parts, the modulus and conversion work as for complex arrays.
v = ar.Quantity(3 + 4j, "V")
print(v.real, v.imag, abs(v), v.to("mV"), v / ar.Quantity(2j, "A"))

25.0 m/s 90.0 km/h
UnitError: incompatible units: km/h and kg
3.0 V 4.0 V 5.0 V (3000+4000j) mV (2-1.5j) V A-1

Quantity.magnitude

The number, in this quantity's unit: a float, or a complex.

Quantity.real

The real part, in the same unit.

Quantity.imag

The imaginary part, in the same unit (0 for a real quantity).

Quantity.conjugate()

The complex conjugate (a real quantity is its own).

Quantity.conj()

The complex conjugate, as conjugate() (numpy's spelling).

Quantity.units

The unit, as a string (as DataArray.units).

Quantity.unit

The unit.

Quantity.dimension

The quantity's dimension.

Quantity.to(units)

The same quantity in another (compatible) unit; for a complex quantity, both parts scale, and a unit with an offset (°C) is an error.

Quantity.to_astropy()

As an astropy.units.Quantity (needs astropy).

Dimension annotations#

annoray.dims names dimensions as classes: they make checked quantities (Length(2.5, "km")), annotate arrays and quantities (DataArray[Velocity]), and annoray.dims.checked() enforces the annotations at call time. Derived dimensions are declared as annoray.dims.Dim subclasses.

from annoray.dims import Length, Time, Velocity, checked

@checked
def speed(d: Length, t: Time) -> Velocity:
    return d / t

print(speed(ar.Quantity(5.0, "km"), ar.Quantity(30.0, "min")).to("km/h"))

10.0 km/h

dims.checked(func)

Check dimension annotations of func's arguments and result at each call: def speed(d: Quantity[Length], t: Quantity[Time]) -> Quantity[Velocity].

dims.Dim(magnitude[, units])

Base of named dimensions: class Jerk(Dim, dimension=Length / Time**3): ....

dims.name_of(d)

The name given to a dimension (the first one, if several), or None.
